# SCA Results

This directory contains results of the SCA pipeline, applied to various MSAs.
The version table below details each version.

| KO     | Version | Description |
| ------ | ------- | ----------- |
| K00370 | `v1_TIGR01580_with_soil_seqs_1000`    | The TIGR01580 set of NarG sequences, along with a set of 85 soil sequences, a superset of the 57 ORFs of interest. Groups defined as the top 5% of an empirical t-distribution fit to the ICAs. |
| K00370 | `v2_TIGR01580_with_soil_seqs_57`    | The TIGR01580 set of NarG sequences, along with the 57 soil sequences of interest. Groups defined as the top 5% of an empirical t-distribution fit to the ICAs. |
| K00370 | `v3_TIGR01580_noX_with_soil_seqs_57`    | The TIGR01580 set of NarG sequences, excluding sequences containing amino acid symbol 'X', along with the 57 soil sequences of interest. Groups defined as the top 5% of an empirical t-distribution fit to the ICAs. |
